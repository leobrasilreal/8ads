# 8ads Website

Landing page institucional da agência 8ads com foco em conversão.

## Estrutura
- `index.html`: home com seções de conversão e prova social.
- `contato.html`: formulário de consultoria gratuita.
- `blog.html`: listagem inicial de conteúdos.
- `styles.css` e `script.js`: estilos globais e interações.

## Execução local
```bash
python3 -m http.server 4173
```

## Manutenção rápida
- Atualize cases e métricas em `index.html`.
- Ajuste contatos e integrações em `contato.html`.
- Conecte formulário a backend/email provider (Webhook, Zapier, etc.).
- Substitua placeholders de analytics/pixel por IDs reais.
